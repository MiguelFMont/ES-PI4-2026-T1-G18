# Logos dos bancos

Usados nos avatares das contas e dos cartões (`Frontend/src/shared/utils/avatar.js`). O nome do arquivo é o código do banco da lista
`GET /v1/accounts/banks`. Se um arquivo não carregar, o avatar volta às iniciais na cor do banco.

As marcas e os logotipos pertencem aos respectivos bancos; aqui são usados só para identificar a instituição, num trabalho acadêmico.
